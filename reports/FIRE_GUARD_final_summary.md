# FIRE-GUARD 3.0 Final Summary

## 1. 한 줄 정의

FIRE-GUARD 3.0은 ASOS/AWS 관측자료, 건조·강풍 특보, 전력설비 위치 데이터를 결합해 전력설비 주변 화재위험도를 산정하고, 고위험 설비의 예방점검 우선순위를 제시하는 기상·공간 융합 의사결정 시스템입니다.

## 2. 핵심 차별점

기존 단순 기상위험 분석은 지역 단위 위험도를 보는 데 그치지만, FIRE-GUARD는 전력설비 좌표 1,387,831개를 1km grid로 구조화하고, 각 grid에 가장 가까운 AWS/ASOS 관측소를 연결해 설비 밀도와 기상 위험을 함께 반영했습니다.

## 3. 사용 데이터

- 전력설비 위치 데이터
- ASOS 시간자료 및 일자료
- AWS 시간자료
- ASOS/AWS 관측소 메타데이터
- 건조·강풍 특보 자료

## 4. 분석 구조

1. 전력설비 좌표 정제
2. 1km grid 기반 설비 밀도 계산
3. 관측소 좌표와 grid 중심점 거리 매칭
4. 일 단위 기상 feature 생성
5. 건조도, 무강수 지속일, 강풍, 특보, 설비 밀도 기반 risk score 계산
6. grid 위험도를 pole 단위로 확장
7. top1/top3/top5/top10 제출 후보 생성
8. top5 baseline 최종 선택

## 6. 최종 판단

현재 산출물은 rule-based baseline이지만, 단순 임의 선택이 아니라 기상위험, 설비 밀도, 무강수 지속성, 강풍, 특보 정보를 결합한 설명 가능한 위험도 산식 기반 결과입니다. 따라서 제출용 1차 baseline과 보고서용 근거 자료로 사용할 수 있습니다.

## 7. 남은 개선 방향

- 실제 화재 발생 label 확보 시 supervised model로 확장
- 위험도 weight 조정 및 threshold calibration
- 지형, 산림, 토지피복, 도로 접근성 feature 추가
- 계절별/월별 feature 확장
- 점검 우선순위 대시보드 고도화
